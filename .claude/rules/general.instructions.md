When creating or changing tools for the MCP Server, follow these guidelines:

- When planning tools, make sure to use the Microsoft Docs MCP server to get authoritiative information about Dataverse API and capabilities.
- Use Web Search for Copilot MCP to find examples of how to use the Dataverse API and capabilities in your tools.
- Cluster tools by their purpose and functionality and use different files for different clusters of tools.
