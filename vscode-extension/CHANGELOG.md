# Change Log

All notable changes to the "dataverse-metadata-mcp" extension will be documented in this file.

## [0.2.1] - 2026-03-31

### Added

- Create Form and Update Form now support creating and updating model-driven forms in Dataverse.

## [0.2.0] - 2026-03-27

### Added

- Create Table now supports ownership types: User, Team, and Business Unit
- Create View Methods

## [0.1.3] - 2024-11-08

### Added

- Initial release
- MCP server definition provider for Dataverse metadata
- Configuration UI for Dataverse connection strings
- Support for bundled and globally installed server
- Commands for configuration and server refresh
- Integration with GitHub Copilot through MCP protocol
- Auto-detection of server installation

### Features

- Seamless GitHub Copilot integration
- Easy connection string management
- Multiple server installation options
- Comprehensive error handling and user guidance
